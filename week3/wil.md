## branch 만들기
처음엔 굳이? 싶었지만 만드는 이유를 듣고는 납득을 했다. 약간 내가 이해한대로 비유를 들자면 굴러가는 자동차에 부품을 공장에서 다 만들어서 추가하는 형식인 것 같다
## css 조작
내부 스타일 사용법과 인라인 스타일과의 우선 순위를 배웠다. 또한 외부 스타일 방식도 배웠다. 되게 있을 법한 기능이었다. 하나하나 다 조작하기엔 시간이 많이 들기 떄문에 유용한 기능이라 생각한다
## branch 합치기
commit하고 push한 뒤 메인에 합치는 법을 배웠다. 합치는 법이 3개 있는 것 같은데 일단은 뭐가 다른진 모르겠지만 시키는대로 했다.
